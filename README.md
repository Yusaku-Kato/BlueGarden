# BlueGarden

**SNS の流れを、静かな庭として眺める。**

BlueGarden は、Bluesky の投稿を植物・光・雨・霧・蛍などの自然環境に変換して描くデスクトップアプリです。投稿本文を読むためのクライアントではなく、SNS 全体の「空気感」を環境アートとして眺めることを目的としています。

| SNS | 庭での表現 |
|---|---|
| 投稿 1 件 | 植物 1 本 |
| 明るい投稿 / 普通の投稿 / 暗い投稿 | 花 / 葉 / トゲのある植物 |
| いいね・リポスト | 植物の大きさと成長の速さ |
| 投稿の勢い | 光の粒・雨・風・蛍 |
| 長期の傾向 | 気候 (花盛りの庭・雨の庭・暗い森) |

## 主な機能

- **ログイン**: App Password、または OAuth (ブラウザ)。「この端末で記憶する」で次回から自動ログイン (OS の資格情報ストアに保存)。
- **フィード**: タイムライン / 保存済みフィード / Discover / フィード URL / キーワード検索 / **Global Garden** (Bluesky 全体。ログイン不要)。
- **演出**: 成長・揺れ・フェード、光の粒、雨、霧、蛍、光、Bloom、昼夜 (PC の時計)、気候、テーマ 4 種。
- **表示**: 2D (PixiJS) / 3D (Three.js, 試験的)、全画面 (F11)、スクリーンセーバーモード、システムトレイ、トレイに閉じる。
- **設定**: 最大植物数、寿命、アニメーション速度、粒子の強さ、風の強さ、各エフェクトの ON/OFF。

## 使い方

1. 起動するとログイン画面が表示されます。
   - **App Password**: Bluesky の 設定 → プライバシーとセキュリティ → アプリパスワード で作成し、ハンドルと一緒に入力します (通常のパスワードは使いません)。
   - **OAuth**: ハンドル・メールアドレス、または空欄のまま「OAuth でログイン (ブラウザ)」を押し、ブラウザで承認します。
   - **Global Garden**: 「ログインせずに Bluesky 全体を眺める」を押します。
2. 右上の「⋯」から 設定 / 全画面 / スクリーンセーバー / ログアウト を選べます。
3. スクリーンセーバーモードは、キー・クリック・マウス移動で解除されます。

## 必要環境 (開発)

- Windows 10/11 (WebView2)。macOS / Linux は未検証です。
- Node.js 22.13 以上
- Rust stable (MSVC ツールチェーン) と [Tauri 2 の前提条件](https://v2.tauri.app/start/prerequisites/)

## セットアップとコマンド

```bash
npm install

npm run tauri dev        # 開発用に起動
npm run tauri build      # リリースビルド (インストーラーを作成)

npm run typecheck        # 型検査
npm run lint             # ESLint
npm test                 # 単体テスト (Vitest)
npm run build            # フロントエンドのビルド
```

開発時のみ、URL に次のクエリを付けると確認用の表示になります (`npm run dev` でブラウザから開く場合)。

| クエリ | 内容 |
|---|---|
| `?stats` | 植物数・粒子数などを画面左下に表示 |
| `?mock` | Bluesky の代わりにダミーの植物を生成 |
| `?mock&weather=rain` | ダミーの天気 (`rain` / `fog` / `night` / `calm` / `busy`) |

## プライバシーとセキュリティ

- 投稿本文は明るい・暗いの判定に一瞬使うだけで、保存も表示もしません。描画には本文を渡しません。
- App Password 自体はどこにも保存しません。「記憶する」を選んだ場合のみ、ログインセッションを OS の資格情報ストア (Windows 資格情報マネージャー) に保存します。
- 通信先は Bluesky 公式のサーバー (bsky.social / *.bsky.network / Jetstream / public.api.bsky.app / plc.directory) に限定しています。
- 設定ファイル (アプリの設定フォルダの `settings.json`) には秘密情報を含みません。

## 既知の制限 (1.0)

- **OAuth** は開発用の loopback クライアントで動作します。ブラウザの許可画面にアプリ名が表示されず、再ログインが必要になる頻度が高めです。
- **対応アカウント**: Bluesky 公式ホスティングのアカウントのみ (独自 PDS は未対応)。
- **感情判定** は単語による簡易方式で、否定表現 (「好きじゃない」など) は区別できません。
- **Global Garden** では投稿量が多いため、一部の投稿だけを植物にしています (全体の勢いは光の粒などに反映)。
- **3D 表示** は試験的です。
- 動作確認は Windows のみです。

## ディレクトリ構成

```text
src/
├─ domain/       投稿・植物・環境のモデルと計算 (フレームワーク非依存)
├─ services/     Bluesky / Jetstream / OAuth / ポーリング
├─ app/          取得 → 植物化 → 描画をつなぐパイプライン
├─ rendering/    PixiJS (2D) と Three.js (3D) の描画エンジン
├─ hooks/        React フック
├─ components/   UI
├─ infra/        ロガー、設定・秘密情報の保存、ウィンドウ状態
└─ config/       定数
src-tauri/       Tauri (Rust): 秘密情報の保存、設定ファイル、トレイ
```
